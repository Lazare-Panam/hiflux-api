## Concepts To Learn Next
- [ ] 2026-10-21 — EF Core composite alternate keys + composite foreign keys (the `(ProductId, CategoryId)` trick on CatalogProduct): why that redundant CategoryId on ProductFilterValue lets the DB *prove* a spec belongs to a filter that's valid for the product's category — this is the "too much work" part that's actually the integrity backbone — SeriesProducts configurator
- [ ] 2026-10-21 — Smart/intelligent part numbers: parse the SKU grammar (NV{pressure}{V/R}S{tube}-{body}) as the source of truth for facets instead of trusting hand-entered specs — it caught 12 malformed rows and a missing Stem facet in the Hiflux needle-valve data — needle-valve seed
- [ ] 2026-10-21 — Don't bind to auto-increment surrogate ids across systems: the frontend SERIES_BRIDGE hardcoded each series' SQL categoryId, which broke when seeds ran in a different order (safety valve expected id 5/6, got another). Fix: key on a stable natural key (Category.Name) and resolve the id at runtime. Rule of thumb — surrogate ids are internal; cross-boundary references should use something stable (name/slug) — series configurator bridge
- [ ] 2026-10-23 — Never store numbers as locale-formatted strings: a price saved as `"1,008.00"` rendered as £1 because `parseFloat("1,008.00")` stops at the comma and returns 1 (same comma that caused Msg 10709 in the SQL VALUES). Lesson: store money as a number (or an unformatted string), format only at display; if you must parse a string, sanitize first (`.replace(/,/g,'')`). This single data-quality issue bit twice — SQL seed AND the Mongo-backed page — regulator £1 price bug
- [ ] 2026-10-23 — Next.js App Router metadata only works in server components: `export const metadata` / `generateMetadata` are ignored in any file with `"use client"`. The existing `returns-policy/page.tsx` is a client component, so it ships NO `<title>`/`<meta description>` — an invisible SEO hole on a page you want indexed. Fix pattern (what the new legal pages do): keep `page.tsx` a server component that exports `metadata`, and move the interactive/MUI presentation into a child `"use client"` component it renders. Worth auditing which other pages are needlessly `"use client"` and losing their metadata — legal pages SEO task
